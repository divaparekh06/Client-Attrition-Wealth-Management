# Decision Log

Every real decision made on this project gets its own dated entry here:
what was decided, why, what alternatives were considered, and (where
relevant) what AI tools were used for and how.

This exists so that:
1. I can defend every choice in an interview, in detail.
2. Anyone reviewing the repo can see the reasoning was genuinely mine.
3. I have a running record to make extending this project next semester
   easier — I won't have to reconstruct *why* I did things.

## How to add an entry

Create a new file: `YYYY-MM-DD-short-title.md`, using this template:

```markdown
# [Decision title]

**Date:** YYYY-MM-DD
**Context:** What problem/question prompted this decision?
**Options considered:** What were the alternatives?
**Decision:** What did I choose?
**Reasoning:** Why this option over the others?
```
